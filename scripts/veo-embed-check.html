Can Veo's own player open inside a different website?

This isolated test tries to display the original public Veo match page in a frame. It does not copy footage, bypass Veo permissions, or change your Touchline projects.

Enter a public Veo link to begin.
The Veo player will be attempted here.

Important: A blank frame, an error screen, or a message saying the site refused to connect means this embed test did not succeed. A frame's load event alone does not mean the match plays.

Open original Veo player

If the frame plays, that confirms viewing can work without Render. It does not establish that Touchline can control Veo's playhead, synchronise tactical overlays, or export clips. Those require an authorised player API or an accessible video file. If the frame is blocked, our free alternative is Companion Mode: use Veo's original player alongside Touchline while keeping timestamps and analysis notes.
